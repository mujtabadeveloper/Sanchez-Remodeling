# Sanchez Remodeling

Static website with all images included.

## GitHub and Vercel
1. Extract this ZIP.
2. Upload all files to the root of your GitHub repository.
3. Import the repository into Vercel.
4. Select Other as the framework. No build command is required; use the repository root as the output directory.

Open index.html locally to preview. The inquiry form opens the visitor's email app; it does not submit to a server.
